# Stack

Read this when starting a project or adding a part to one, to know what it is built with and what it starts from. A repository that already has a stack keeps it. Changing a repository's stack is a real trade-off, with a decision record.

## Websites

Static sites, such as brand, product and company sites, are built with Astro and Tailwind CSS.

- **Start from the template.** Create the repository from [wyrd-company/astro-template](https://github.com/wyrd-company/astro-template), and run its `./init.sh` in the devcontainer. The template's README and its skill cover the rest: the alternatives to choose from, forms, deployment.
- **Interactive parts** are React islands, with shadcn/ui components.

## Web applications

Web applications are built with Vite, React, the TanStack libraries for routing and data, shadcn/ui components, and Tailwind CSS v4.
