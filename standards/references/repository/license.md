# LICENSE

Every public repository _MUST_ have a LICENSE file. Private repositories _MAY_ have one.

## Public Repos

- Apache 2.0 by default for projects with branding or are more involved.
- MIT for repos simpler projects with no branding.
- A repo with just data/info should use a Creative Commons license.
- We inherit the license when we fork.
- If the project is part of another ecosystem, we generally prefer following the license from that ecosystem.
